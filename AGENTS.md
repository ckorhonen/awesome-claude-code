# Repository instructions

This repository is a curated Markdown resource list: `README.md`, its logo, and `LICENSE`. There is no application source, dependency manifest, or test/lint/build/typecheck toolchain. The contribution-guidelines section is still marked under construction, so match adjacent entries and category/TOC structure rather than inventing project automation.

For list changes, check the destination and description of the changed resource, duplicate entries, Markdown anchors, and the appropriate category. The README explicitly labels star counts as static snapshots; do not present them as current measurements or refresh the whole list for an unrelated edit. Preserve attribution and licensing.

Use `git diff --check -- <changed-paths>` plus a focused Markdown/link review. Remote availability checks should be limited to changed links when needed; never install or run a listed agent/plugin merely to validate an entry.

Complete the authorized change through relevant verification and repair of introduced failures. Resolve routine implementation choices directly; ask only for information or decisions that materially affect the result. If blocked, name the affected action and missing prerequisite, continue independent work, and close with changed paths, checks actually run, and unverified behavior.
